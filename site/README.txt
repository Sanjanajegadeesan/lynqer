LYNQER + THE DELIVERY BOY WEBSITE
Upload every file/folder to your hosting root (public_html). Open index.html.
- Change app link: replace href="#" on "Download" buttons (search "Download Lynqer") in each .html file.
- WhatsApp number / email: js/main.js (CONFIG at top).
- Email form uses FormSubmit.co: submit once from the live site, then click the activation link sent to admin@thedeliveryboy.in. Until activated (or if offline) it opens the visitor's mail app.
- Images: assets/img/ (replace with your own files using same names).
